# JavaScript Dates and Regex

This repository contains two simple JavaScript programs based on the concepts taught in the course video.

## Programs Included

### 1. JavaScript Dates

The Dates program demonstrates basic JavaScript Date concepts, including:

- Creating a current date using `new Date()`
- Creating a specific date and time
- Creating a date using milliseconds since the Unix Epoch
- Accessing date components
- Getting the year
- Getting the month
- Getting the day
- Getting hours
- Getting minutes
- Getting seconds
- Formatting a date using `toLocaleDateString()`
- Manipulating dates using `setDate()` and `getDate()`
- Comparing two dates

### 2. JavaScript Regex

The Regex program demonstrates basic Regular Expression concepts, including:

- Literal characters
- Character classes
- Quantifiers
- `+` - matches one or more occurrences
- `*` - matches zero or more occurrences
- `?` - matches zero or one occurrence
- Anchors
- `^` - matches the beginning of a string
- `$` - matches the end of a string
- Regex modifiers
- `i` - case-insensitive matching
- `g` - global matching
- Testing a string using the `test()` method
- Using a Regex pattern to check an email address
